# Security Policy & Asset Protection

## Overview

This repository maintains the verified profile configuration, custom vector art, and intellectual property of **Irfan Haider Abir**. We take both software security and intellectual property protection seriously.

## Scope & Protection Policy

- **Protected Assets:** All custom SVG graphics, animated terminal interfaces, and vector banners are protected under proprietary copyright.
- **Branch Segregation:** Assets are isolated across dedicated branches (`assets-header`, `assets-banner`, `assets-snake`) to safeguard source designs.
- **Watermarking:** Every distributed vector graphic contains embedded metadata and legal ownership descriptors.

## Reporting Security Issues & IP Infringements

If you identify a security vulnerability, an exposed secret, or an instance of unauthorized asset copying/plagiarism, please report it privately:

- **Email:** [hello@iabir.me](mailto:hello@iabir.me)
- **Subject:** `[Security/IP Notice] Brief description`
- **Response Time:** We investigate and respond to legitimate inquiries within 24–48 hours.

> [!NOTE]
> Please do **not** open public issues for security vulnerabilities or DMCA/copyright inquiries. Use the direct email above for confidential and prompt handling.
